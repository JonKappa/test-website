# test-website
https://jonkappa.github.io/test-website/

Built with [Astro](https://astro.build), Vue and [Tailwind CSS](https://tailwindcss.com).

- `npm run dev` – start the dev server
- `npm run build` – type-check and build to `dist/`
- `npm run deploy` – build and publish to GitHub Pages
- `npm run test:e2e` – build the site and run the Playwright browser tests (run `npx playwright install chromium` once first)
